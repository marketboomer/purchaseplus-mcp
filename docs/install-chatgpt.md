# Install PurchasePlus in ChatGPT

1. Enable Developer mode.
2. Open **Settings → Apps / Connectors** (wording varies by plan) and add a connector.
3. Set the MCP server URL to `https://purchaseplus.com/mcp`.
4. Choose OAuth.

The same git repository, [https://github.com/marketboomer/purchaseplus-mcp](https://github.com/marketboomer/purchaseplus-mcp), is the Agent Plugin if you install from git.

## Skills

If the ChatGPT plugin or app install includes this repository, the bundled skills apply. Otherwise, call `list_plugin_skills` first and follow those texts. The how-to skill still points at [https://learn.purchaseplus.com/](https://learn.purchaseplus.com/).
