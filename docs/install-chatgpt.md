# Install PurchasePlus in ChatGPT

1. Enable Developer mode.
2. Open **Settings → Apps / Connectors** (wording varies by plan) and add a connector.
3. Set the MCP server URL to `https://purchaseplus.com/mcp` for purchaser, or `https://purchaseplus.com/mcp/supplier` for supplier.
4. Choose OAuth.

Dual-role users add the surface that matches the active organisation. Supplier MCP is list/inspect plus entitled report export only.

The same git repository, [https://github.com/marketboomer/purchaseplus-mcp](https://github.com/marketboomer/purchaseplus-mcp), is the Agent Plugin if you install from git.

## Skills

If the ChatGPT plugin or app install includes this repository, the bundled skills apply. Otherwise, tell the model to use [https://learn.purchaseplus.com/](https://learn.purchaseplus.com/) for how-to documentation.
